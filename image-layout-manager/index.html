Image Layout Manager

Assemble multi-panel layouts with plot-area alignment, LaTeX support, PiP overlays, MCP-assisted editing, and Vector-Sharp PDF export — built for publication-ready figures.

Get it from Microsoft Store ⬡ View on GitHub
Features
Everything you need for journal figures

From layout to export, in a single desktop app.

📊

Align Plot Areas

Mark each chart's plotting area, then match plot heights and bottom axes across panels — in grid or freeform layouts, without touching the source files.

🔤

Text Size Matching

Pick text in SVG or raster panels and match its size across the whole figure, leaving the original files untouched.

Σ

LaTeX Support

Render complex formulas, symbols, and chemical notations directly on panels using standard LaTeX syntax.

🖼️

Picture-in-Picture (PiP)

Create insets and magnified views with ease. Overlay sub-images with customizable borders to highlight key details.

📐

Hierarchical Splitting

Split cells infinitely in vertical or horizontal stacks to create sophisticated, multi-tiered layouts.

📤

Vector-Sharp PDF Export

Export publication-ready PDFs with high-DPI image embedding while keeping text and labels as resolution-independent vector objects.

📏

Integrated Scale Bar Tool

Add and fine-tune professional scale bars—an essential requirement for microscopy and imaging figures.

🏷️

Shared Group Labels

Span a single label across several cells to mark rows, columns, or conditions — drag the label band outward to adjust its stacking order.

🪄

One-Click Auto Layout

Drop a batch of images or a whole folder to get an arranged multi-panel grid, then optimize cell ratios and page size with a single click.

🗂️

Freeform Layer Stack

Switch to freeform placement and reorder overlapping panels and insets by dragging them in the Layers panel, Photoshop-style.

🎓

Guided Tutorials

Nine built-in lessons walk you through layout, subdivision, plot alignment, labels, text sizes, and export in a disposable practice project.

🤖

AI / MCP Assisted Editing

Connect Claude, Cursor, Windsurf, Cline, or other MCP hosts to build, style, annotate, preview, save, and export figures through the running app.

CLI
CLI and MCP automation for repeatable workflows

Render, pack, inspect, and connect AI agents through the bundled CLI — same quality as the GUI, plus live MCP control.

🖥️

Render

Export .figpack / .figlayout to PDF, TIFF, JPG, or PNG with the same renderer as the GUI.

📦

Pack / Unpack

Bundle layouts with assets into .figpack, or extract .figpack to folders.

🔍

Inspect

Query page size, DPI, cell counts, and metadata (text or JSON output).

🔌

MCP adapter

Run imagelayout-cli.exe mcp so AI hosts can call the app's 39 layout, styling, PiP, scale-bar, text, and export tools.

# Pixel-perfect PDF render at project DPI
imagelayout-cli.exe render figure_4.figpack -f pdf -o figure_4.pdf
# Fast preview PNG with custom DPI
imagelayout-cli.exe render figure_4.figlayout -f png --dpi 150
# Print-ready CMYK TIFF with ICC profile
imagelayout-cli.exe render figure_4.figpack -f tiff --cmyk --icc-profile "path/to/profile.icc" -o fig.tiff
# MCP adapter for Claude, Cursor, Windsurf, Cline, etc.
imagelayout-cli.exe mcp

Available only in Windows Installer. See CLI docs for full documentation.
