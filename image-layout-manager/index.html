REFLOW

Plots that fit their panels

Reflow resizes native plots to fit their panels while keeping font sizes and line widths at exact point values. Plots on the same row align axes automatically.

Works with native .ilmplot.svg files. Standard images and SVGs keep their original proportions. Paused when cell aspect ratio is locked or manual plot-area alignment is active.

Features
Built for scientific figures

Everything needed to take raw plots and microscopy images to journal standards.

Editable Plot Editor

Build line, scatter, bar, and distribution plots from Excel/CSV. Add error bars and p-values, and reopen saved .ilmplot.svg files anytime.

Align Plot Areas

Align axis boxes across different charts so plot heights and baselines match, even when tick labels or legends differ in size.

Text Size Matching

Sample text in any SVG or bitmap panel and scale panels to match font sizes across the figure.

LaTeX Support

Write math, Greek letters, and chemical formulas directly in labels using standard LaTeX syntax.

Picture-in-Picture (PiP)

Add zoom insets or overlay sub-images with custom borders and leader lines.

Hierarchical Splitting

Split any cell horizontally or vertically as many times as needed for nested layouts.

Vector-Sharp PDF Export

Export PDFs and SVGs with high-DPI bitmaps and vector text, or CMYK TIFFs with ICC profiles.

Scale Bars

Add calibrated scale bars to microscopy and imaging panels with custom units, lengths, and placement.

Shared Group Labels

Span headers across multiple rows or columns to label experimental conditions, and drag to reorder nested bands.

Freeform Layer Stack

Switch from grid to freeform mode anytime and reorder overlapping panels in the Layers list.

Guided Tutorials

Step-by-step interactive projects built into both ILM and the Plot Editor.

AI / MCP Assisted Editing

Connect Claude, Cursor, Windsurf, or any MCP client to arrange panels, style labels, and export figures live.

CLI & MCP
Automate from the terminal or AI agents

Use imagelayout-cli for headless rendering in scripts, or run it as an MCP server for AI assistants.

Render

Render .figpack or .figlayout files to PDF, TIFF, JPG, or PNG with the exact same engine as the GUI.

Pack / Unpack

Bundle a layout and all linked images into a single portable .figpack archive, or unpack it back to a folder.

Inspect

Print page dimensions, DPI, cell counts, and layout metadata as plain text or JSON.

MCP adapter

Expose layout, styling, and export tools over stdio so MCP clients can drive the live app or edit files headlessly.

# Pixel-perfect PDF render at project DPI
imagelayout-cli.exe render figure_4.figpack -f pdf -o figure_4.pdf
# Fast preview PNG with custom DPI
imagelayout-cli.exe render figure_4.figlayout -f png --dpi 150
# Print-ready CMYK TIFF with ICC profile
imagelayout-cli.exe render figure_4.figpack -f tiff --cmyk --icc-profile "path/to/profile.icc" -o fig.tiff
# MCP adapter for Claude, Cursor, Windsurf, Cline, etc.
imagelayout-cli.exe mcp

Bundled with the Windows and macOS apps. See the CLI docs for all commands and MCP setup.
