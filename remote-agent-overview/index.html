Try

  • Tap a computer, then a project, to reach its sessions. Use the bottom bar (the left rail in landscape) to switch levels, and the breadcrumb to go back up.
  • Amber tiles need you. Tap one to answer or approve without leaving the board.
  • Tap any other session for a one-screen summary and a box to steer it.
  • Full conversation / Full UI opens today's detailed UI.

How to read a tile

running needs you done failed stopped / offline
  • Fill = plan progress (steps done / total)
  • Size = urgency (waiting tiles grow, finished ones shrink)
  • Text = title, one “now” line, step count, time. No chat.
  • A waiting session also colours its project and computer, and shows up in the Needs you lane at every level.
