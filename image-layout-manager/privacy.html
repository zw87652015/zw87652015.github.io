Privacy

Privacy Policy

Effective: 22 September 2026 · Last updated: 22 September 2026

ImageLayoutManager is a local desktop application. It does not require an account, include advertising or analytics, upload your projects, or send crash reports. Its only automatic Internet request is a version check. The details and local-only exceptions are explained below.

1. Scope

This policy applies to the ImageLayoutManager desktop application, its command-line tools, and this product website. It explains what information these services access, store, or transmit.

2. Information processed by the application

Files and projects

The application accesses only the files and folders you choose to open, import, save, export, or reveal. Projects, images, OCR processing, exports, settings, recovery snapshots, and cache files remain on your device. The developer does not receive their contents.

Automatic update check

About 1.5 seconds after startup, the application requests a small version manifest from luojiajiang.uk. The request does not include your name, email address, project data, a device identifier, or an advertising identifier. As with any web request, the web server and its hosting or network providers receive your IP address, request time, requested URL, and technical request headers. This information is used only to deliver the manifest and maintain the security and reliability of the service.

Project lock files

While a project is open, the application may create a temporary lock file beside it. The lock file contains the operating-system user name, computer name, and process ID so another local session can identify that the project is in use. It is removed after a normal close and is never sent to the developer. If the project folder is synchronized or shared by another service, that service may copy the lock file.

Local logs and recovery data

Crash logs, recovery snapshots, preferences, and caches are stored locally. They are not uploaded automatically. If you choose to send a log or project when requesting support, it will be processed only to respond to your request.

Optional MCP connection

The optional MCP server is disabled unless you enable it. It listens only on your device (localhost) and uses a session token. A client you configure may request project information, screenshots, file operations, or exports. Information sent to that client is governed by the client provider's privacy terms; it is not sent to the ImageLayoutManager developer.

3. What the application does not do

  • No user account or sign-in.
  • No advertising, analytics SDK, behavioural profiling, or cross-app tracking.
  • No automatic upload of projects, images, exports, OCR content, crash reports, or usage history.
  • No sale or rental of personal information.

4. Product website

When you visit this website or download a release, the hosting and delivery services receive ordinary web-request information such as IP address, time, URL, browser headers, and download status. The website uses local storage only to remember your English or Chinese language choice. It does not use advertising cookies or analytics. The product page may load the Inter web font from Google Fonts; that request is subject to Google's privacy terms. Links to GitHub and other sites are governed by those sites' own policies.

5. Sharing and disclosure

The developer does not sell personal information. Limited technical request data may be processed by website hosting, content-delivery, and network providers as necessary to operate the update endpoint, website, and downloads. Information may also be disclosed where required by law or necessary to protect the service and its users.

6. Retention and control

Local application data remains under your control and can be removed by deleting the relevant projects, exports, caches, logs, settings, or the application itself. Temporary lock files are normally removed when a project closes. Web-server security and access logs may be retained for a limited period according to operational needs and the policies of the relevant hosting provider.

7. Security

Reasonable technical measures are used to limit collection and protect the services, but no storage or transmission system can be guaranteed completely secure.

8. Children

ImageLayoutManager is a general-purpose scientific figure tool and is not directed to children. The developer does not knowingly collect personal information from children.

9. Changes to this policy

This policy may be updated when application or website behaviour changes. The effective and last-updated dates at the top of this page will identify the current version.

10. Contact

For privacy questions or requests, contact: me@luojiajiang.uk
